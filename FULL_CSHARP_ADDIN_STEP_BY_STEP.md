# Полный гайд для новичка: как добавить новый макрос `PropertyN` в C# SolidWorks Add-in

Ниже инструкция для человека, который **никогда не работал с C# и Visual Studio**.

---

## Что вы получите в итоге

После выполнения шагов у вас в add-in появится команда `PropertyN`:
- команда будет видна в вашем TaskPane (где список команд строится из `List<ISwCommand>`);
- при запуске команда откроет окно настроек;
- во время обработки будет показываться форма прогресса (аналог вашего `frmProgress`);
- по окончании отчёт покажется через `swApp.SendMsgToUser2(...)`.

---

## Шаг 1. Подготовить Visual Studio

1. Установите Visual Studio 2022 (Community достаточно).
2. При установке выберите workload **.NET desktop development**.
3. Убедитесь, что SolidWorks уже установлен на этом же ПК.

---

## Шаг 2. Открыть ваш проект add-in

1. Запустите Visual Studio.
2. Нажмите **Open a project or solution**.
3. Откройте ваш `.sln` add-in проекта.
4. В Solution Explorer найдите проект, где уже лежат ваши команды `ISwCommand`.

---

## Шаг 3. Проверить, что в проекте есть интерфейс `ISwCommand`

Откройте файл, где объявлен интерфейс. Должно быть:

```csharp
public interface ISwCommand
{
    string Name { get; }
    string Description { get; }
    void Execute(ISldWorks swApp);
}
```

Если интерфейс уже есть — ничего менять не нужно.

---

## Шаг 4. Добавить файл команды

1. В Solution Explorer кликните правой кнопкой по папке `Commands` (или другой, где у вас команды).
2. Нажмите **Add** → **Class...**.
3. Имя файла: `SwPropertyNCommand.cs`.
4. Вставьте в этот файл содержимое из репозитория файла `SwPropertyNCommand.cs`.

---

## Шаг 5. Проверить NuGet/ссылки на SolidWorks Interop

В проекте должны быть доступны пространства имён:

- `SolidWorks.Interop.sldworks`
- `SolidWorks.Interop.swconst`

Если Visual Studio подсвечивает их красным:

1. Правый клик на проект → **Manage NuGet Packages...**
2. Установите (или обновите) пакеты Interop, которые используете в проекте.
3. Либо добавьте COM references (если у вас проект на COM-ссылках, а не NuGet):
   - `SolidWorks <version> Type Library`
   - `SolidWorks Constant type library`

---

## Шаг 6. Проверить, что WinForms доступен в проекте

Команда использует программно созданные формы (`SettingsForm`, `ProgressForm`).

Если проект на .NET Framework — обычно ничего не нужно.
Если .NET (Core/5+) — проверьте, что в `.csproj` есть:

```xml
<UseWindowsForms>true</UseWindowsForms>
```

---

## Шаг 7. Зарегистрировать команду в вашем списке TaskPane

Найдите место, где вы формируете `List<ISwCommand>`.

Пример:

```csharp
var commands = new List<ISwCommand>
{
    new SwPropertyNCommand(),
    // остальные команды...
};
```

Важно: не забудьте `using` для namespace, где лежит `SwPropertyNCommand`.

---

## Шаг 8. Скомпилировать проект

1. В верхнем меню Visual Studio нажмите **Build** → **Build Solution**.
2. Дождитесь `Build succeeded`.
3. Если есть ошибки:
   - проверьте namespace и `using`;
   - проверьте, что `ISwCommand` доступен;
   - проверьте ссылки на SolidWorks Interop.

---

## Шаг 9. Запустить add-in в SolidWorks

Зависит от вашей инфраструктуры add-in. Обычно:

1. Собираете DLL add-in.
2. Регистрируете add-in (ваш текущий способ регистрации).
3. Открываете SolidWorks.
4. Включаете add-in в **Tools → Add-Ins**.

---

## Шаг 10. Проверка в TaskPane

1. Откройте ваш TaskPane `Vasilev Tools`.
2. Найдите команду `PropertyN`.
3. Нажмите команду.
4. Должно открыться окно настроек (если `ShowSettingsOnStart = true`).

---

## Шаг 11. Проверка формы прогресса (аналог frmProgress)

Во время выполнения должна появиться отдельная форма прогресса:

- вверху текст статуса;
- полоса прогресса;
- процент выполнения.

Это реализовано внутри `SwPropertyNCommand` как класс `ProgressForm`.

---

## Шаг 12. Где лежат настройки

Настройки пишутся в файл:

- `PropertyN.ini`

Путь определяется рядом с текущим macro path, а если его нет — через `Environment.CurrentDirectory`.

---

## Шаг 13. Что внутри C# команды уже реализовано

1. Двухпроходная обработка:
   - тихий проход (сборки, покупные, исключения),
   - обычный проход (геометрия).
2. Фильтрация read-only (по настройке).
3. Очистка пользовательских свойств и BBox (по настройке).
4. Запись свойств детали/сборки.
5. Создание BBox и привязка размеров/массы/материала.
6. Закрытие документов кроме стартового (по настройке).
7. Отчёт через `swApp.SendMsgToUser2(...)`.

---

## Шаг 14. Быстрый smoke test

1. Откройте тестовую сборку с деталями.
2. Запустите `PropertyN` из TaskPane.
3. В настройках включите `ShowReport = true`, `EnableBBox = true`.
4. Нажмите `ОК`.
5. Убедитесь, что:
   - показывается прогресс,
   - по завершению есть отчёт,
   - в деталях появились ожидаемые свойства.

---

## Шаг 15. Частые проблемы и решения

### Проблема: команда не появляется в TaskPane
- Проверьте, что `new SwPropertyNCommand()` реально добавлен в `List<ISwCommand>`.
- Проверьте, что нужный namespace подключён.

### Проблема: ошибка `ISldWorks`/Interop
- Проверьте ссылки на `SolidWorks.Interop.sldworks` и `SolidWorks.Interop.swconst`.

### Проблема: форма не открывается
- Проверьте, что проект собран с поддержкой WinForms.
- Проверьте, что `Execute(swApp)` реально вызывается при нажатии кнопки.

### Проблема: не создаётся `PropertyN.ini`
- Проверьте права записи в папку.
- Проверьте значение, которое возвращает `swApp.GetCurrentMacroPathName()`.

---

## Шаг 16. Что можно улучшить потом (необязательно)

1. Добавить логирование в файл.
2. Добавить отдельное окно детального прогресса с возможностью отмены.
3. Разделить большой класс на:
   - `SwPropertyNCommand` (оркестрация),
   - `PropertyNProcessor` (бизнес-логика),
   - `PropertyNSettingsService` (INI),
   - `PropertyNSettingsForm` и `PropertyNProgressForm`.
