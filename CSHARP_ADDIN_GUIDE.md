# Как использовать `SwPropertyNCommand` в вашем C# аддине

## 1) Что добавлено

Добавлен класс `SwPropertyNCommand` в файле `SwPropertyNCommand.cs`.

Класс:
- реализует `ISwCommand`;
- использует только переданный `ISldWorks swApp`;
- может показывать WinForms-настройки внутри `Execute(...)`;
- сохраняет настройки в `PropertyN.ini` рядом с макросом/рабочей папкой.

## 2) Подключение в TaskPane (динамический список команд)

Пример регистрации:

```csharp
var commands = new List<ISwCommand>
{
    new SwPropertyNCommand(),
    // другие команды...
};
```

Дальше ваш текущий механизм генерации кнопок TaskPane по `List<ISwCommand>` вызовет `Execute(swApp)` для этой команды.

## 3) Особенности реализации

- Нет ручного подключения к SolidWorks (`new SldWorks()` не используется).
- По завершению используется `swApp.SendMsgToUser2(...)`.
- Форма настроек создаётся полностью программно (без Form Designer).

## 4) Что делает команда

1. Берёт активный документ.
2. Загружает настройки из `PropertyN.ini`.
3. При `ShowSettingsOnStart = true` открывает окно настроек.
4. Делает 2 прохода по деталям/сборкам:
   - тихая обработка (покупные/исключения/сборки),
   - обычная обработка геометрии.
5. Проставляет свойства, при необходимости строит Bounding Box.
6. Показывает итоговый отчёт через `SendMsgToUser2`.

## 5) Ограничения / примечания

- В текущей версии уже добавлен программный аналог `frmProgress` (`ProgressForm`) внутри `SwPropertyNCommand`.
- Форма прогресса показывается во время двух проходов и обновляется через `UpdateProgress(...)`.
