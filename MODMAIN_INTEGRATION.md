# Куда вставлять `modMain` и как запускать

1. В VBA Project:
   - `Insert -> Module` -> назовите модуль `modMain`.
   - Вставьте туда содержимое файла `modMain.bas`.

2. Убедитесь, что добавлены:
   - модуль `modSettings` (файл `modSettings.bas`),
   - форма `frmSettings` + её code-behind из `frmSettings_CODE.txt`,
   - ваша форма прогресса `frmProgress`.

3. Запуск:
   - ставите курсор в `Sub main()` модуля `modMain`,
   - нажимаете `F5`.

4. Поведение по умолчанию:
   - при каждом запуске `main` сначала откроется окно настроек.
   - если нажать `Отмена`, выполнение макроса остановится.
